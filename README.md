\# Router Security Auditor



A simple Python-based tool for auditing the security of your home router. It scans common ports, identifies open services, and provides risk assessment with recommendations.



\## Features



\- Scans a configurable list of TCP ports.

\- Loads a knowledge base (JSON) with descriptions, risk levels, and recommendations for each port.

\- Outputs a brief coloured report to the console.

\- Saves a detailed report to a text file.

\- Ethical: designed for auditing your own devices only.



\## Requirements



\- Python 3.8+

\- No external libraries required (uses standard library only).
